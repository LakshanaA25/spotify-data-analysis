# spotify-data-analysis

### Project Overview
This data analysis project investigates the specific audio characteristics and features that drive track popularity on Spotify. By examining data extracted from the Spotify API, the project aims to answer a core question: What characteristics are associated with song popularity on Spotify?

Tools: Python, Pandas, Matplotlib, Seaborn
